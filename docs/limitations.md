# Известные ограничения

## Модель и данные

- **Допущения в ТТХ.** Часть параметров отсутствует в паспортах и задана командой; в `backend/data/fleet.yaml` они перечислены в поле `assumed` у каждого борта и нагрузки. Главные: крейсерская скорость Геоскан 201 (19,4 м/с = 210 км / 3 ч), ёмкость АКБ Геоскан 801, фокусное расстояние Sony на 201, размер пикселя тепловизора 801, время смены АКБ (201 — 20 мин, мультироторы — 10 мин), эффективный сектор LiDAR AGM-MS3 (90°).
- **LiDAR и геофизика** моделируются на Геоскан 401 — в приложении к ТЗ таких нагрузок нет; ТТХ взяты из руководства Геоскан 401.
- **Энергия.** Бюджет вылета считается по паспортной продолжительности полёта с резервом; для мультироторов — квадратичная поправка на ветер с коэффициентом-допущением. Модель не калибрована по телеметрии; масса нагрузки, температура и износ АКБ не учитываются.
- **Ветер** постоянный по области, высоте и времени; порывы не моделируются. Развороты самолёта строятся без учёта сноса (трохоидальные пути Techy & Woolsey не реализованы), время разворота — по воздушной скорости.
- **Перелёты по графу видимости** для самолёта строятся ломаной без учёта радиуса разворота в вершинах.
- **Рельеф** — модель поверхности (DSM) 30 м: учитывает лес и крупные здания, но не отдельные мачты и ЛЭП. Высоты — над геоидом EGM2008. Без сети и без тайлов в кэше план строится относительно точки старта (с предупреждением).

## Планирование

- **Эвристический оптимум.** Распределение — балансировка долей и локальный поиск; глобальный оптимум не гарантируется. Фронт Парето строится взвешенной суммой и методом ε-ограничений по сетке значений: точки между узлами сетки не ищутся, для областей больше 20 км² точек меньше (ради времени расчёта).
- **Одна база на борт.** Все вылеты борта начинаются и заканчиваются на одной ВПП; посадка на другую ВПП для продолжения работ не планируется. Резервные площадки используются только для проверки аварийного ухода.
- **Одновременные полёты не разводятся.** Участки бортов не пересекаются, но транзиты разных бортов могут пересекаться в плане; эшелонирование по высоте и времени не выполняется.
- **Самолёт у запретных зон.** Самолёту оставляется запас на вынос петли разворота; если в парке нет мультиротора, эта полоса остаётся неснятой (показывается в покрытии и предупреждении).
- **Одно направление галсов** на всю область (по самому производительному борту). Для сильно разнородных по форме участков отдельный выбор направления не делается.
- **Секущие маршруты** для геофизики строятся по всему участку борта и режутся на вылеты вместе с основными галсами.

## Программные

- Рассчитанные планы хранятся в памяти процесса до перезапуска; многопользовательская работа и история не предусмотрены.
- Экспорт — GeoJSON и KML (формат из ТЗ). Загрузка в автопилот (MAVLink, формат Geoscan Planner) не реализована.
- Нормативные ограничения (ИВП, план полёта) не проверяются: сервис учитывает только заданные пользователем разрешённую зону, NFZ и потолок высоты.
- Подложка OpenStreetMap загружается из интернета; без сети карта будет без подложки, расчёт работает.
