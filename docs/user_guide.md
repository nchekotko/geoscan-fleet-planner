# Руководство пользователя

Интерфейс открывается в браузере: при запуске через Docker — http://127.0.0.1:8000, в режиме разработки — http://127.0.0.1:5173.

Слева — панель параметров, справа — карта (OpenStreetMap). Внизу справа на карте — легенда этапов полёта.

## 1. Исходные данные

**Быстрый старт.** В блоке «Сценарий» выберите тестовый сценарий — все слои и парк загрузятся автоматически:

| Сценарий | Что показывает |
|---|---|
| `demo_basic` | 6,3 км², запретная зона внутри области, 4 разных борта, две ВПП, ветер 5 м/с |
| `geophysics_401` | Магнитная съёмка двумя Геоскан 401: малая высота, огибание рельефа, секущие маршруты |
| `lidar_401` | LiDAR-съёмка с заданной плотностью точек |
| `strong_wind` | Ветер 11 м/с: часть бортов исключается, у 401 поднимается скорость |
| `large_mixed_fleet` | 110 км², разрешённая зона, две NFZ, 5 бортов — разбиение с учётом дальности |

**Своя задача.** В блоке «Геометрия»:
1. «Область съёмки» — щелчками по карте задайте вершины многоугольника, замкните щелчком по первой вершине.
2. «Разрешённая зона» (необязательно) — граница разрешённого воздушного пространства.
3. «+ Запретная зона» — сколько угодно NFZ.
4. «+ ВПП» — щелчок по карте ставит взлётно-посадочный пункт (A, B, …).
5. «+ Резервная площадка» — площадки аварийной посадки.

Под кнопками — список объектов; «✕» удаляет объект, «очистить всё» — всю геометрию. Esc отменяет рисование.

**Импорт.** «Импорт KML/GeoJSON» загружает контуры из файла: после чтения выберите, чем сделать полигоны (область съёмки, разрешённая зона, запретные зоны) и точки (ВПП, резервные площадки).

**Правка.** «Редактировать геометрию» делает полигоны и площадки редактируемыми: перетаскивайте вершины, тяните середину стороны, чтобы добавить вершину, правый щелчок удаляет вершину; ВПП и резервные площадки перетаскиваются.

**Сценарии.** «Сохранить сценарий» скачивает текущие входные данные в JSON, «Загрузить сценарий» открывает такой файл (формат совпадает с тестовыми сценариями).

## 2. Парк

«+ добавить борт» — выбор модели (Геоскан 201, Gemini, 801, 401). Для каждого борта можно изменить имя и базу (ВПП); «авто» — ближайшая к его участку база. Нагрузка подбирается автоматически под тип съёмки.

## 3. Съёмка и условия

- **Тип съёмки:** RGB, мультиспектральная, ИК, LiDAR, геофизическая. Поля меняются под тип: GSD и перекрытия для камер, плотность точек для LiDAR, шаг галсов для геофизики.
- **Потолок высоты** — ограничение разрешённого объёма над землёй.
- **Ветер** — скорость и направление, откуда дует (0° — с севера, 90° — с востока). «Ветер задан»: «на высоте полёта» или «у земли, 10 м» — во втором случае ветер пересчитывается на рабочую высоту каждого борта (на 150 м он примерно в 1,5 раза сильнее).
- **Перекрытие полос LiDAR** — для LiDAR-съёмки (по умолчанию 20 %).
- **Резерв заряда** — доля ёмкости, которая не планируется (по умолчанию 20 %).

## 4. Критерий и расчёт

Ползунок «Критерий оптимизации»: правый край — минимум времени выполнения работ, левый — минимум суммарного налёта, между — компромисс.

- **«Рассчитать план»** — один план по выбранному критерию (от 0,1 с для небольших областей до ~10 с для 100 км²).
- **«Сравнить варианты (фронт Парето)»** — набор недоминируемых планов на графике «время работ — налёт». Щелчок по точке открывает план.

## 5. Результат

- **Карта:** участок каждого борта своим цветом, галсы — сплошные, секущие маршруты — длинный пунктир, развороты — тонкие, перелёты и возврат — короткий пунктир. Наведите на линию — вылет, этап, длительность.
- **Показатели:** время работ, суммарный налёт, число вылетов, покрытие (жёлтым — если меньше 99,5 %). Над результатом — какой критерий использован.
- **Устаревший план.** Если после расчёта изменить входные данные, результат затемняется, а экспорт блокируется до пересчёта.
- **Вылеты во времени:** полоса на каждый вылет; промежутки — смена АКБ.
- **Таблица бортов:** высота, число вылетов, налёт, время окончания, худшее время ухода на ближайшую площадку.
- **Исключённые борта** — с причиной (ветер, нет нагрузки, выгоднее не задействовать).
- **Предупреждения** — нехватка резерва для ухода на площадку, выход за дальность радиоканала, неснятые участки, сближение бортов, падение перекрытия на попутном галсе, превышение GSD над низинами рельефа, резервные площадки в запретных зонах.

## 6. Экспорт

В таблице бортов — ссылки «GeoJSON» и «KML» на задание каждого борта; «Скачать все задания (ZIP)» — все файлы плана. KML открывается в Google Earth и QGIS; GeoJSON — в QGIS, geojson.io и других ГИС.
